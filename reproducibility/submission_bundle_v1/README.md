# PP submission reproduction bundle v1

`manifest.json` records the code commit, environment, primary numerical claims, and SHA-256 hashes of the local raw JSON artifacts. Large datasets and result arrays are intentionally excluded from Git. Run the listed commands from the repository root after installing the benchmark dependencies and placing datasets under `data/`.

The Oxford result is retained as a negative external outcome-held-out evaluation. Do not regenerate the manifest after changing a result without assigning a new bundle version.
